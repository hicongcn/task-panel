# 路线图

## v0.1(当前 MVP)

- [x] 管理员初始化 + JWT 登录 + 失败锁定
- [x] 定时任务 CRUD + Cron 调度 + 运行/停止 + 超时/重试 + 进程组终止
- [x] 脚本文件管理(树/读写/上传/重命名)+ 路径穿越防护
- [x] 脚本执行(python/node/bash/go)+ 调试运行内联代码
- [x] SSE 实时日志 + 历史日志 + 原始下载票据
- [x] 环境变量 CRUD + 分组 + 脱敏 + 注入(过滤危险变量)
- [x] Docker 部署 + 非 root 运行
- [x] 安全基线(JWT 黑名单 / CORS 严格 / IP 仅信回环 / 日志转义)

## 设计原则

- **稳定优先**:每个版本都保证 `go test ./...` + `npm run build` 通过、Docker 冒烟可用,再合入下一批功能。
- **安全不欠债**:命令执行、路径、鉴权、日志渲染四条线在每个版本都保持当前 MVP 的防护标准,新增功能不得削弱既有防护。
- **独立实现**:功能与架构模式可借鉴同类项目,但代码、命名、UI、文案全部自研。
