# 路线图

## v0.1(当前 MVP)

- [x] 管理员初始化 + JWT 登录 + 失败锁定
- [x] 定时任务 CRUD + Cron 调度 + 运行/停止 + 超时/重试 + 进程组终止
- [x] 脚本文件管理(树/读写/上传/重命名)+ 路径穿越防护
- [x] 脚本执行(python/node/bash/go)+ 调试运行内联代码
- [x] SSE 实时日志 + 历史日志 + 原始下载票据
- [x] 环境变量 CRUD + 分组 + 脱敏 + 注入(过滤危险变量)
- [x] Docker 部署 + 非 root 运行
- [x] 安全基线(JWT 黑名单 / CORS 严格 / IP 仅信回环 / 日志转义)

## v0.2(当前)

- [x] 通知渠道(Webhook / Telegram / Bark / 邮件)
- [x] 任务结果通知(成功/失败/终止)
- [x] 备份与恢复(加密备份 + 定时备份)
- [x] Monaco 在线编辑器(替换 textarea,带语法高亮)
- [x] 审计日志

## v0.3(当前)

- [x] IP 白名单(仅允许指定网段访问面板)
- [x] 依赖管理(pip / npm 可视化安装)

> 已决定不做:Git 订阅(自动拉取脚本)、多用户角色体系(保持单管理员)。

## v1.0(当前)

- [x] 系统监控仪表板(CPU/内存/磁盘)
- [x] 2FA / TOTP(登录双因素)
- [x] CLI 运维工具(账号恢复 / 日志清理 / 任务触发)
- [x] Open API(参考青龙结构:应用管理 + client_id/secret + token + scopes)

> 已决定不做:Windows 免安装打包。

## v1.1(当前,v1.0 功能增强)

- [x] 任务分组/标签(标签管理、按标签筛选、批量启用/禁用/运行/删除)
- [x] 批量导入/导出(任务/脚本/环境变量 JSON 导出与导入恢复)

> 已决定不做:任务依赖编排、Webhook 触发、会话管理、环境变量加密存储、执行统计图表、脚本版本历史。

## v1.2(当前,功能增强)

- [x] 面板标题/图标自定义
- [x] 日志自动清理策略
- [x] 自定义推送模板
- [x] 系统事件告警
- [ ] 拖拽排序/移动(环境变量排序、脚本树拖拽)

## 设计原则

- **稳定优先**:每个版本都保证 `go test ./...` + `npm run build` 通过、Docker 冒烟可用,再合入下一批功能。
- **安全不欠债**:命令执行、路径、鉴权、日志渲染四条线在每个版本都保持当前 MVP 的防护标准,新增功能不得削弱既有防护。
- **独立实现**:功能与架构模式可借鉴同类项目,但代码、命名、UI、文案全部自研。
